В мире развивается тренд на онлайн-обучение. 
Но для веб-разработчика важно не только обучиться, но и знать, как реализовать платформу для онлайн-обучения. 
Поэтому новая задача касается разработки LMS-системы, 
в которой каждый желающий может размещать свои полезные материалы или курсы.

1. Запуск проекта через `docker-compose up --build`:** Этот шаг строит образы для всех сервисов (если они были изменены) и запускает их.
2. Остановка проекта через `docker-compose down`:** Это останавливает все контейнеры и очищает ресурсы.
3. Проверка сервисов:** В этом разделе описано, как проверить работу Django, PostgreSQL и Redis.
   - Для Django проверка происходит через открытие веб-страницы на `localhost:8000`.
   - Для PostgreSQL используется команда для подключения к контейнеру и выполнения SQL-запроса.
   - Для Redis — команда для проверки отклика с помощью `ping`.
